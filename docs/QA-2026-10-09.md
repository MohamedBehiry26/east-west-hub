# Local website QA — 9 October 2026

Environment: Angular at localhost:4200; API at 127.0.0.1:5080; local PostgreSQL. This is a local development assessment, not a production deployment or penetration test.

## Passed

- Backend: `dotnet test SpaceMedia.sln --configuration Release --no-restore`: 68/68 tests.
- Frontend: full suite 67/67 tests, then detail regression suite 4/4 including one newly added missing-content test. All 68 distinct frontend tests passed.
- Angular production build; standalone TypeScript checks for Cloudflare middleware, robots and sitemap functions.
- All 96 Arabic/English public URLs currently listed in the API sitemap rendered a heading. No horizontal overflow or failed completed images was observed on those desktop page loads.
- 44 collection/detail/navigation pages also checked at 390 CSS pixels; no horizontal overflow or failed completed images observed. Home inspected separately on desktop and mobile.
- Watch, podcasts and video details additionally checked at actual CSS viewport widths 360, 853 and 1600 (browser zoom influenced requested device dimensions).
- Watch search: unmatched query shows empty state; clearing restores the existing video. Category filtering hides nonmatching video and clearing the filter restores it.
- Global search for the current video's title returns its detail link.
- Mobile menu opens and closes with Escape.
- Video detail loads the linked YouTube iframe on activation. Actual playback advanced from 10 to 29 seconds across scrolling, without restarting. Hero activation uses the configured YouTube ID. Deferred loading and stable iframe binding are also covered by automated tests.
- Eight public API endpoint families returned HTTP 200 for both `lang=ar` and `lang=en`; unsupported language returned 400; nonexistent video returned 404; unauthenticated admin videos returned 401; sitemap returned 200.
- No application console errors/warnings observed during the checked public flows. This does not cover every external YouTube request or lazy asset outside the viewport.

## Fixed during QA

- Detail titles no longer append a second `East West Hub` when the saved SEO title already includes it.
- Failed/missing details replace old page metadata, remove old media/schema metadata and use `noindex, follow`. A regression test checks navigating from an existing detail to a missing detail; live missing-video metadata was verified.
